Features

Everything your game needs

📋
Game feed

See all upcoming games at a glance — capacity, location, date, and who's already in.

⏳
Smart waitlist

Game full? Join the waitlist. When someone drops out, you're automatically promoted — no chasing the group chat.

🔔
Push notifications

Get notified when you're added to a game, confirmed off the waitlist, or a game is cancelled.

👥
Team generator

Balanced random team splits generated in one tap. Teams are saved so everyone can check on match day.

🔑
Invite-only admins

Admins are added via one-time invite codes. Players just sign up — no password, no fuss.

⚡
Real-time updates

Player lists update live as people join or leave. Everyone always sees the same thing.

How it works

Up and running in minutes

1
Admin creates a game

Pick the sport, set the date, location, and max players. Pre-add anyone you want — they'll get a notification immediately.

2
Players sign up

Players join with their phone number — one tap to join a game or the waitlist if it's full. No passwords, no friction.

3
Pitch handles the rest

Waitlist promotions happen automatically. Generate balanced teams on match day. Done.
